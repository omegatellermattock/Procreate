## ⚡ Features that actually matter

### 🖌️ Brushes that feel right
Over **200 built-in brushes** across Sketching, Inking, Painting, Artistic, and Calligraphy. Import custom `.brush` sets. Every stroke responds to pressure, tilt, and velocity — just like you remember.

### 🗂️ Layers without limits
Stack as many layers as your RAM allows. **Masks, clipping masks, alpha lock, blend modes** — the full toolkit. Reorder with drag-and-drop, group them, merge them.

### ✍️ Pen input done properly
Native support for **Wacom, Huion, XP-Pen, Surface Pen**, and Apple Pencil via iPad Sidecar. Pressure curves are configurable per device. No jitter, no lag, no "why does my line look like stairs."

### 🎯 The Procreate tricks
- **QuickShape** — hold to snap perfect lines, circles, and polygons.
- **StreamLine** — smooth shaky strokes in real time.
- **ColorDrop** — drag a color blob into a shape to fill it.
- **Gesture controls** — two-finger tap to undo, pinch to zoom, rotate to... rotate.

### 🖥️ Built for Windows
Hotkeys you can remap. Mouse-wheel zoom. Right-click context menu. **Dark and light themes.** Touch gestures on Windows 11 tablets. It doesn't feel like a port — it feels native.

### 🚀 Fast where it counts
Hardware acceleration via **DirectX 12**. Canvases up to **8K**. PSD export **40% faster** than v0.9. Opening a 50-layer file doesn't make you wait for coffee.
